# Refactorizar Java ☕🔧

Repositorio de ejercicios prácticos orientados a la **refactorización de código** y la aplicación de principios de *Clean Code* en Java[cite: 2].

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado en diferentes casos de estudio y ejemplos prácticos:

* **`src/src/fecha/`**: Ejercicio enfocado en la validación y gestión de fechas (`Fecha.java`), mejorando la legibilidad, encapsulación y manejo de errores.
* **`src/src/refactor01/`**: Primer caso práctico de refactorización de código legacy o estructurado hacia un diseño más limpio (`Main_01.java`).
* **`src/src/refactor02/`**: Segundo caso práctico enfocado en la optimización de lógica y modularización (`Main_02.java`).

## 🚀 Tecnologías y Requisitos

* **Lenguaje:** Java[cite: 2]
* **Paradigma:** Programación Orientada a Objetos (POO)

## 🎯 Objetivos de Aprendizaje

* Identificar "olores de código" (*code smells*).
* Aplicar técnicas de refactorización para mejorar la mantenibilidad del software.
* Separar responsabilidades y aplicar buenas prácticas de diseño de clases y métodos.
